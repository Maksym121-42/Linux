# Загальне завдання
У програмі використано значення, близьке до максимально можливого для 32-бітного типу time_t (2147483647). Далі за допомогою циклу виконується збільшення змінної до досягнення граничного значення.

Отримане значення перетворюється у дату за допомогою функцій gmtime() та asctime().                
**Результат:**  
<img width="504" height="83" alt="image" src="https://github.com/user-attachments/assets/adb3c40c-a5ce-493a-a8a5-95d87f84be9f" />      


Програма виконувалась на 64-бітній системі, що підтверджується розміром типу time_t (8 байт). Однак у коді було штучно обмежено діапазон значень до меж 32-бітного типу.     
Це дозволило змоделювати ситуацію переповнення time_t, яка характерна для 32-бітних систем. У результаті було отримано граничне значення 2147483647
