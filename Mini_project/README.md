# Мініпроект
**Тема:** Реалізація аналога конвеєра команд

## Мета роботи
Створити кілька процесів, організовувати обмін даними між ними через канали (`pipe`) та виконати перенаправлення стандартних потоків (`dup2`) для побудови конвеєра команд Linux.

## Умова завдання
Створити програму, яка виконує аналог команди:

`cat file.txt | grep word | wc -l`

З використанням:
- `pipe()`
- `fork()`
- `dup2()`
- `exec()` (`execlp()`)

## Що реалізовано в програмі
У програмі створено:
- **2 канали**:
  - `pipe1` для передачі даних від `cat` до `grep`;
  - `pipe2` для передачі даних від `grep` до `wc -l`.
- **3 дочірні процеси**:
  1. Процес `cat` читає вхідний файл.
  2. Процес `grep` відбирає рядки, що містять задане слово.
  3. Процес `wc -l` рахує кількість відібраних рядків.

## Логіка реалізації
1. Головний процес перевіряє аргументи командного рядка:
   - ім’я файлу;
   - слово для пошуку.
2. Створюються два канали через `pipe()`.
3. Після першого `fork()` дочірній процес:
   - перенаправляє `stdout` у `pipe1`;
   - виконує `cat file.txt`.
4. Після другого `fork()` дочірній процес:
   - перенаправляє `stdin` з `pipe1`;
   - перенаправляє `stdout` у `pipe2`;
   - виконує `grep word`.
5. Після третього `fork()` дочірній процес:
   - перенаправляє `stdin` з `pipe2`;
   - виконує `wc -l`.
6. Батьківський процес закриває всі файлові дескриптори каналів і чекає завершення дочірніх процесів через `waitpid()`.
