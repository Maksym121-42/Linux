Це спрощена реалізація утиліти `more`.


## Завдання 5

Результат запуску:  
`./Lab7_5`  
програма вивела список файлів із поточного каталогу та всіх вкладених підкаталогів. Вивід вийшов дуже великим, оскільки обхід виконується рекурсивно для всього дерева директорій.

Програма відкриває каталог через `opendir()`, читає елементи через `readdir()`, пропускає службові `.` і `..`, формує повний шлях до кожного елемента та перевіряє його тип через `stat()`. Якщо елемент є звичайним файлом (`S_ISREG`) — шлях виводиться на екран; якщо елемент є каталогом (`S_ISDIR`) — викликається рекурсивний обхід цього підкаталогу. Таким чином реалізовано перелік усіх файлів у поточному каталозі та в усіх його підкаталогах.
