# Варіант 11

## Тема роботи
Дослідження впливу зміни пріоритету процесів через `nice()` на розподіл процесорного часу в Linux.

## Хід роботи
У програмі створено 4 дочірні процеси за допомогою `fork()`.
Кожен процес виконує однакове CPU-bound навантаження: довгий цикл обчислень без операцій введення-виведення.
Для перших двох процесів залишено стандартний пріоритет (`nice=0`), для інших двох встановлено нижчий пріоритет (`nice=10`).
Для кожного процесу виміряно час виконання та виведено `pid`, значення `nice` і тривалість роботи.

## Результати виконання
- `pid=60325 nice=0 time=0.518 s`
- `pid=60326 nice=0 time=0.556 s`
- `pid=60327 nice=10 time=0.555 s`
- `pid=60328 nice=10 time=0.553 s`

Отримані значення часу виконання для процесів з `nice=0` і `nice=10` у цьому запуску майже однакові.
Це означає, що в конкретних умовах експерименту вплив пріоритету проявився слабо.
Причиною може бути невелика тривалість обчислень, мала кількість процесів або недостатнє завантаження системи під час запуску.
