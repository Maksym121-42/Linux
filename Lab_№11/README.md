# Завдання 1
**Варіант:** 11

## Мета роботи
Реалізувати програму, у якій кожен потік обробляє тільки свій набір сигналів, використовуючи синхронне очікування через `sigwaitinfo`.

## Що реалізовано в програмі
У програмі створено 2 потоки:
- `Thread-1` обробляє сигнали: `SIGUSR1 (10)` і `SIGINT (2)`.
- `Thread-2` обробляє сигнали: `SIGUSR2 (12)` і `SIGTERM (15)`.

### Логіка реалізації
1. На рівні процесу потрібні сигнали блокуються через `pthread_sigmask`, щоб вони не оброблялися випадково.
2. Для кожного потоку формується власна маска сигналів (тільки його сигнали).
3. Усередині кожного потоку запускається цикл очікування:
   - потік викликає `sigwaitinfo`;
   - при отриманні сигналу виводить:
     - назву потоку;
     - номер сигналу;
     - `PID` процесу-відправника (`info.si_pid`).
4. Головний потік надсилає процесу сигнали (`kill(getpid(), ...)`) для демонстрації роботи.
5. Після обробки потрібної кількості сигналів потоки завершуються.

## Як виконувалась перевірка
- У консольному виводі перевірено, що:
  - `Thread-1` приймає тільки `10` і `2`;
  - `Thread-2` приймає тільки `12` і `15`;
  - виводиться коректний `PID` джерела сигналів.
